How to Create a Talos Snapshot

Method 1: Rescue Mode (Recommended)

  1. Create temporary server: hcloud server create --type cx11 --name talos-snapshot --image ubuntu-22.04 --location nbg1
  2. Enable rescue & reboot: hcloud server enable-rescue talos-snapshot && hcloud server reboot talos-snapshot
  3. SSH into rescue system: ssh root@<server-ip>
  4. Download and write Talos image:
    cd /tmp
    wget -O /tmp/talos.raw.xz https://factory.talos.dev/image/376567988ad370138ad8b2698212367b8edcb69b5fd68c80be1f2ec7d603b4ba/v1.11.0/hcloud-amd64.raw.xz
    xz -d -c /tmp/talos.raw.xz | dd of=/dev/sda && sync
    shutdown -h now
  5. Create snapshot: hcloud server create-image --type snapshot --description "Talos v1.11.0" talos-snapshot
  6. Get snapshot ID: hcloud image list
  7. Delete temporary server: hcloud server delete talos-snapshot
