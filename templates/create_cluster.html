How to Create a Talos Snapshot

  1. Create a server in Hetzner Cloud with any image
  2. Boot the server into rescue mode
  3. Download and write the Talos image:
    wget -O - https://github.com/siderolabs/talos/releases/download/v1.11.2/hcloud-amd64.raw.xz | xz -d | dd of=/dev/sda
  4. Reboot the server
  5. Create a snapshot from the server
  6. Copy the snapshot ID and use it above

Cluster Creation Info

  • The cluster will be created with the Cilium CNI and Gateway API support
  • All nodes will be provisioned in a private network
  • Estimated deployment time: 5-10 minutes
  • Kubeconfig will be saved to ./output/kubeconfig
